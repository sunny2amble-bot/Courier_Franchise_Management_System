# Courier Franchise Management System

## Project Description
The Courier Franchise Management System is a web-based application designed to manage courier franchise operations.

## Features
- Customer Management
- Parcel Booking
- Parcel Viewing and Tracking
- Delivery Agent Management
- Hub Management
- Cash on Delivery (COD) Payment Management

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MySQL

## How to Run the Project
1. Install Node.js and MySQL.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Run `npm install`.
5. Start the server using `npm run dev`.
6. Open http://localhost:3000 in your browser.

## Development Tool
Visual Studio Code

## Project Purpose
This project helps manage customer information, parcel bookings, delivery agents, courier hubs, and COD payment records in one application.
